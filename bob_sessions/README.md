# Bob Sessions — Hackathon Submission Screenshots

This folder stores IBM Bob task session consumption summary screenshots required for the Ripple hackathon submission.

## Guidelines

- Screenshots should be **PNG** where possible.
- Each filename must clearly identify the team/project, participant, task number, and a short task description.

## Naming Pattern

```
ripple_<participant>_task<NN>_<short-description>_summary.png
```

## Examples

```
ripple_erick_task01_mcp_foundation_summary.png
ripple_erick_task02_git_health_tools_summary.png
ripple_erick_task03_bob_integration_summary.png
```

## How to Capture

1. Complete a Bob task session.
2. Open the Bob session summary panel.
3. Take a screenshot of the full summary (tokens used, tools called, session duration).
4. Save the file into this folder using the naming pattern above.
